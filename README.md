# 🌍 Adventure Awaits - Tour & Travel Website

🔗 **Live Demo:** https://adventure-await-tour-travel-agency.netlify.app/

---

## 📌 About the Project
Adventure Awaits is a responsive Tour and Travel website designed to help users explore travel packages, view destinations, and book their dream trips easily.

This project focuses on front-end development using HTML, CSS, and JavaScript with an attractive UI and smooth user experience.

---

## ✨ Features
- 🏝️ Explore travel packages
- 🖼️ Image gallery for destinations
- 🧾 Booking form for users
- 📱 Fully responsive design
- 🎯 Smooth navigation and UI
- ⭐ Customer reviews section

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome (Icons)
